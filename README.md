# FlatFlow — SMD Group Project

## Project Theme

FlatFlow is a shared budgeting application for students living together.

The application helps roommates manage shared expenses, keep track of budgets, calculate who owes money, and view monthly spending reports.

Our group consists of five members. Each member is responsible for developing one module and has one shared responsibility within the team.

## Module Descriptions

**1. Expenses**

Manage shared expenses such as rent, groceries and electricity.

**2. Members**

Manage the roommates who use the application.

**3. Budgets**

Allow roommates to set budgets and track spending limits.

**4. Settlements**

Calculate how much each roommate owes or should receive.

**5. Monthly Reports**

Provide an overview of monthly expenses and spending.

## Project Organization

We will use GitHub to organize our work. Each member will develop their own module, while the shared team repository will contain our project information, responsibilities and GitHub issues.

Our project board will track the progress of all five modules.
